# Планировщик: PWA + Telegram-бот (общие данные)

Приложение и бот работают с одними и теми же задачами и категориями.
Данные хранятся в **Netlify Blobs** — бесплатное встроенное хранилище Netlify,
отдельный хостинг/база данных не нужны. Всё укладывается в бесплатный тариф
Netlify при личном использовании.

## Структура проекта

```
public/                  ← сама PWA (то, что было у вас раньше)
netlify/functions/data.js       ← API для PWA (общее хранилище)
netlify/functions/telegram.js   ← вебхук Telegram-бота
netlify/functions/_lib/store.js ← общий доступ к данным
netlify.toml, package.json
```

## Шаг 1. Выложить проект на Netlify

1. Зайдите на https://app.netlify.com → **Add new site** → **Deploy manually**
   (или подключите Git-репозиторий, если предпочитаете — тогда каждое обновление
   будет деплоиться автоматически).
2. Перетащите **всю папку проекта** (не архив, а распакованную папку) в окно
   деплоя. Netlify сам поставит зависимость `@netlify/blobs` и соберёт функции
   по `netlify.toml`.
3. После первого деплоя откройте **Site configuration → Environment variables**
   и добавьте:

   | Переменная | Значение |
   |---|---|
   | `API_KEY` | придумайте длинную случайную строку — это пароль для доступа к вашим задачам из PWA |
   | `TELEGRAM_BOT_TOKEN` | токен бота (см. Шаг 2) |
   | `TELEGRAM_WEBHOOK_SECRET` | ещё одна случайная строка (защита вебхука от чужих запросов) |
   | `ALLOWED_USER_ID` | ваш numeric Telegram user id (см. Шаг 2) — бот будет отвечать только вам |

4. Сделайте **Deploy → Trigger deploy**, чтобы переменные подхватились.

## Шаг 2. Создать Telegram-бота

1. В Telegram откройте **@BotFather** → `/newbot` → задайте имя и username.
   BotFather выдаст **токен** — вставьте его в `TELEGRAM_BOT_TOKEN`.
2. Узнайте свой **user id**: напишите в Telegram боту **@userinfobot** — он
   пришлёт ваш числовой Id. Вставьте его в `ALLOWED_USER_ID`.

## Шаг 3. Подключить вебхук бота к Netlify

После деплоя у вас будет адрес вида `https://ваш-сайт.netlify.app`.
Выполните (замените `<TOKEN>`, `<ваш-сайт>`, `<WEBHOOK_SECRET>` на свои значения)
— можно прямо в браузере, вставив ссылку в адресную строку:

```
https://api.telegram.org/bot<TOKEN>/setWebhook?url=https://<ваш-сайт>.netlify.app/.netlify/functions/telegram&secret_token=<WEBHOOK_SECRET>
```

В ответ должно прийти `{"ok":true,"result":true,...}`. Готово — бот работает.

Проверить состояние вебхука можно так:
```
https://api.telegram.org/bot<TOKEN>/getWebhookInfo
```

## Шаг 4. Открыть приложение

Откройте `https://ваш-сайт.netlify.app` в браузере (можно установить как PWA
«на главный экран»). При первом запуске приложение спросит **ключ доступа** —
введите то же значение, что и в `API_KEY`. Дальше ключ сохранится в браузере.

## Как пользоваться ботом

Напишите боту `/start` — откроется меню:
- **📋 Список задач** — все задачи, фильтры «Все / Активные / Выполненные»,
  внутри задачи: отметить выполненной, изменить название/заметку/категорию/
  приоритет/дату/время, чек-лист (добавление, отметка, удаление пунктов),
  удаление задачи;
- **➕ Новая задача** — пошагово: название → категория → дата → приоритет;
- **🗂 Категории** — создание, переименование, смена цвета, удаление.

Изменения, сделанные в боте, появляются в приложении при следующем открытии
или возврате в него (и наоборот) — оба используют одно и то же хранилище.

## Важно

- Бот **приватный**: отвечает только пользователю с `ALLOWED_USER_ID`.
  Если переменную не задать, бот будет отвечать всем, кто его найдёт, —
  не рекомендуется.
- Всё бесплатно в рамках бесплатного тарифа Netlify (300 кредитов/мес,
  этого более чем достаточно для личного планировщика). Отдельный сервер
  или хостинг не требуется — Netlify Functions работают по запросу.
